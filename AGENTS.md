# Ограничения на редактирование кода (Инструмент edit)
- НИКОГДА не генерируй функции целиком, если в них больше 15 строк. Входной JSON ломается из-за незакрытых строк (JSON Parse error).
- Используй инструмент `edit` точечно. Вместо замены всей функции, заменяй конкретный блок кода, используя точные маркеры строк начала и конца.
- Если нужно добавить много кода, разбивай изменения на несколько последовательных мелких вызовов `edit`.
